# Visual assets

`arabic-stone-logo.png` is the user's supplied official logo, copied without changing the image. It is displayed on the login page, navigation and documents. CSS crops the surrounding wallpaper for the logo proportions; the printable version uses a background crop so PDF export preserves those proportions.

`black-gold-marble.png` was generated using the built-in image generation tool for the Arabic Stone application. It is used on the navigation, dashboard banners, login background and stationery brand mark. Decorative catalogue swatches are illustrative, not photographs of the actual articles.

Generation prompt:

> Use case: photorealistic-natural. Asset type: premium marble texture wallpaper for a black, ivory and antique gold business dashboard. Primary request: edge-to-edge flat photographic scan of polished black marble, very dark charcoal black base, fine naturally branching muted warm gold and occasional ivory mineral veins. Elegant restrained real stone, veins concentrated more around edges and diagonal corners, broad calm dark areas. Landscape composition. No text, logos, borders, objects, UI or lighting glare. High resolution natural detailed stone texture.
