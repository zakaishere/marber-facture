# Invoice design backup - 2026-10-20

This is the exact print design before adding the contact footer and location QR.
Original source paths are preserved below this directory. SHA-256 hashes are in
manifest.json. No invoices, credentials, or business records are included.

To restore the previous design, copy the files under frontend/ back to the same
paths at the repository root, then rebuild the frontend. Restoring these files
also restores the previous print model and converter; check compatibility with
any newer changes before restoring. Database changes are not reversed by this backup.
